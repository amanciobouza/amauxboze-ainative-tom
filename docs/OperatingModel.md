# Amaux Bozé AI Operating Model

## Core model

> Agent = responsibility  
> Skill = capability  
> Workflow = collaboration  
> Tool = access  
> Model = intelligence  
> Obsidian = memory  
> LangGraph = process orchestration  
> OpenSpec = software change governance

## Workflow organization

Initial business processes to model:

1. New Watch Development
2. Product Launch
3. Content Campaign
4. Customer Feedback → Learning
5. Market Intelligence → Strategic Insight

Business process descriptions belong in Obsidian. Technical workflow implementations belong in LangGraph and are specified first through OpenSpec.

## Decision-rights principle

Agents may research, synthesize, draft, propose, and execute explicitly approved low-risk actions. Consequential actions require human approval until explicitly delegated.

Examples:
- Publishing public content: approval required initially.
- Changing prices: approval required.
- Approving production: founder only.
- Sending customer communication: approval required initially.
- Writing research findings and learnings to Obsidian: allowed.

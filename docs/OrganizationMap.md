# Organization Map

## Build Organization

```text
                           Amancio
                      Founder / Owner
                            │
        ┌───────────────────┼────────────────────┐
        │                   │                    │
  All eight agents report directly to Amancio:
  Elena · Lucien · Élodie · Nora · Marc · Maya · Sophie · Kai

  Elena coordinates cross-functional execution; coordination is not
  a separate reporting line and grants no additional approval rights.
```

## Operating Principle

The organization is intentionally flat.

- Amancio owns final strategic and consequential decisions.
- Elena coordinates cross-functional execution.
- Functional agents own domain work.
- LangGraph orchestrates processes across roles.
- Skills are reusable capabilities, not roles.
- Tools are controlled interfaces to systems.

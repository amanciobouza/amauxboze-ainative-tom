# Delta for Customer Feedback Learning

## ADDED Requirements

### Requirement: Raw feedback remains an observation

The system MUST persist raw customer feedback separately from later interpretation.

### Requirement: Structured classification

The workflow MUST classify feedback into an explicit category before routing.

### Requirement: Response drafting without unauthorized sending

The workflow MAY draft a customer response but MUST NOT send consequential communication without approval.

### Requirement: Pattern detection

The workflow MUST distinguish isolated feedback from recurring patterns.

### Requirement: Functional routing

The workflow MUST route implications to the appropriate functional roles based on category.

### Requirement: Prioritization

The workflow MUST prioritize feedback using explicit criteria such as frequency, customer friction, strategic relevance, revenue impact, brand impact, and effort.

### Requirement: Founder approval for consequential change

When a proposed action affects product specification, pricing, brand principles, public commitments, or material operating policy, the workflow MUST pause for founder approval.

### Requirement: Durable learning

The workflow MUST persist the signal, pattern, decision, action, and outcome when known.

# Delta for Content Campaign

## ADDED Requirements

### Requirement: Campaign starts from explicit objective

The workflow MUST require a campaign objective and audience before content creation.

### Requirement: Message before channel execution

The workflow MUST establish message architecture before channel strategy and content production.

### Requirement: Audience and evidence validation

The workflow MUST perform customer relevance and evidence checks before publication.

### Requirement: Brand review before founder approval

All final content MUST pass Brand Review before reaching the founder gate.

### Requirement: Founder approval before publication

The workflow MUST pause for founder approval before external publication.

### Requirement: Publishing permission

External publication MUST be blocked when the publishing agent lacks the required action permission.

### Requirement: Idempotent publishing

Resuming a workflow MUST NOT publish the same campaign twice.

### Requirement: Campaign learning

The workflow MUST support a post-publication learning stage using content, commercial, customer, and market signals.

### Requirement: Durable knowledge capture

Campaign artifacts, decisions, publish results, and learnings MUST be persisted to Obsidian with trace metadata.

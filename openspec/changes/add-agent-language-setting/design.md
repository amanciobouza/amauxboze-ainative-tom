# Design

Add typed AppSettings.agent_language (de/en), default de for existing settings. The shared live Model Gateway adds a trusted system instruction to all three transports. Natural-language values use the selected language while schema keys, identifiers, enums, citations and exact quotations retain their contract/source values. Settings are snapshotted per execution section; existing artifacts and explicit simulation fixtures are not translated. Expose the selector in Settings and persist through the existing endpoint/repository. No provider fallback or approval change.
